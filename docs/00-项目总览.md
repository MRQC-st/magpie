# Magpie 部署总览

> 项目 SSOT。服务器：腾讯云 `ubuntu@43.131.227.120`（Ubuntu 22.04，systemd 用户服务）。
> 创建于 2026-10-19；2026-10-19 同日更正域名（原先误用 `autofile.cc.cd`，已全部拆除）。

## 一句话

magpie v0.1.1292 二进制部署在腾讯云，作为**模型网关**：所有 agent（本机 Claude Code / 服务器上的 OpenCode、Hermes 等 / 其他设备）通过同一个网关走 provider，网页只用于管理。

## 公网入口

| 用途 | 地址 | 鉴权 |
|---|---|---|
| 管理网页 | `https://magpie.sunfolower.cn/?k=<MAGPIE_WEB_KEY>` | URL key → 登录 cookie |
| OpenAI 兼容 API | `https://magpie.sunfolower.cn/v1/...` | `Authorization: Bearer <gateway key>` |
| Anthropic Messages | `https://magpie.sunfolower.cn/v1/messages` | 同上（或 `x-api-key`） |
| Gemini | `https://magpie.sunfolower.cn/v1beta/...` | 同上 |
| 本机回环（服务器上） | `http://127.0.0.1:3425`（网关）、`:3430`（网页） | 回环无需 key |

- 域名 zone：`sunfolower.cn`，CF 主账号，zone id `1b8762a91fa7b922850021f3f1518343`
- DNS：`magpie.sunfolower.cn` → A `43.131.227.120`（CF 橙色云，proxied）
- 证书：CF 边缘自动签发（当前 LE `CN=sunfolower.cn`，2026-11-27 到期后由 CF 续期）

## 架构

```
浏览器/agent ──HTTPS──► CF 边缘 ──HTTP:80──► 腾讯云 nginx (conf.d/magpie.sunfolower.cn.conf)
                                              ├─ /v1/ , /v1beta/ ──► 127.0.0.1:3425 (magpie gateway)
                                              └─ /              ──► 127.0.0.1:3430 (magpie web)
```

- nginx 站点在 **`/etc/nginx/conf.d/magpie.sunfolower.cn.conf`**（不是 sites-enabled；原因见 `02-域名与回源.md`）
- magpie 服务：`~/.config/systemd/user/magpie.service`，`magpie serve --web=0.0.0.0:3430`，`MAGPIE_ADDR=0.0.0.0:3425`

## 常用命令（服务器上）

```sh
export PATH=$PATH:/home/ubuntu/.local/bin
magpie daemon status                 # 服务状态 + 网页链接
magpie daemon restart                # 更新后重启
journalctl --user -u magpie -f       # 日志
magpie gateway-key list              # 网关 key 列表
magpie gateway-key add "文件名"      # 新增设备 key（明文只显示一次）
```
