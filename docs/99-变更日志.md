## 2026-10-27 · LobsterAI 插件（试点第一例）：逆向项目 → magpie 插件

> 目标：把 `model-reverse`（mrv 自有逆向网关）里已逆向成功的应用逐步转成 magpie 插件，本期是第一个试点 **LobsterAI**（网易有道 Electron 客户端，M22 逆向成果）。

- **产物**：`plugins/lobster/`（合并版 magpie 插件，MIT，保留原作者 Jasery 署名）。
  - 主干 = 参考插件 `Jasery/opencode-lobster-auth`；回填自有逆向实现 6 项能力：
    每日签到（`auth.checkin`）／双层 JSON 兼容解析／refresh 归因字段／
    客户端版本动态读 asar／sqlite 回写（updated_at 自适应）／模型目录三级降级。
  - 三个登录方式：0 浏览器（has 账号）、1 本机桌面导入（只读）、2 服务器副本导入（换 token，零交互）。
  - 统一用 `node:sqlite`（node v24 与 Bun 1.4.2 双端可用），非 `bun:sqlite`。
- **服务器部署**（`ubuntu@43.131.227.120`）：
  - 插件 `/home/ubuntu/magpie-plugins/lobster`（folder plugin 就地加载，spec 即路径）
  - 凭据副本 `~/.config/LobsterAI/lobsterai.sqlite`（权限 600，来自本机桌面端库只读拷贝）
  - `magpie plugin options` 设 `serverCopyDb` 指向副本
  - `magpie plugin login lobster 3` ⇒ 落盘为普通 oauth 账号（`source=server-copy`，access/refresh 齐全，expires 2026-11-26）⇒ 续期交给 magpie `auth.refresh`
  - 签到开关 `settings.json` 的 `pluginCheckins.lobster=true`
- **实测**：30 个模型（显示上游真名）、`provider test` 通过、三条断言全过 ——
  非流式调用方拿到完整 `chat.completion`（强制 SSE 合并生效）／
  思考档位 none→reasoning 0 字符、high→140／kimi-k3 原生 `tool_calls`。
  签到返回 `{outcome:"done", streak:21}`（判据正确：已领不谎报 claimed）。
