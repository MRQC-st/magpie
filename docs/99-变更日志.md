## 2026-10-30 · MonkeyCode 双通道签到打通（+ 自动续期上线）：A 通道靠「每日领积分」，不是充值 <!-- DEC-MAG-008 -->

> 全文见 `16-MonkeyCode双通道与签到.md` §三。**本条修正了上一条的错误结论。**

- 🔴 **纠正**：上一条说「A 通道 400 余额不足 = 百智云账户没钱，要充值」——**错**。
  真相是**两条通道的余额来自两个不同站点的钱包，签到端点各走各的**：
  | | A（百智云） | B（MonkeyCode 官方云） |
  |---|---|---|
  | 钱包站 | `baizhi.cloud`（`baizhi_session`，30 天） | `monkeycode-ai.com`（`monkeycode_ai_session`，**7 天**） |
  | 签到 | `POST /api/v1/user/wallet/daily-temporary-credit`（+100 积分/天） | `POST /api/v1/users/wallet/checkin`（+100 积分/天） |
  | 验证码 | 自研 Cap PoW（c=50 s=32 d=3，FNV-1a+xorshift32+SHA-256） | 同族 PoW，插件自带实现 |

  经网关 `magpie provider test baizhi` → ✓ anthropic / ✓ responses（`✗ chat` 正常，baizhi 无 chat 协议）。
  ⇒ **不用充值**；这也解释了逆向项目 09-24「A 打光 → 自愈」= 每日额度重置/领取。
