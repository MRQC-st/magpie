## 采用模式

沿用 sunfolower.cn 系已有的「**CF 托管 HTTPS + 源站 HTTP 回源**」模式（同 `omniroute` / `sub2api` 等）：

```
浏览器/agent ──HTTPS──► CF 边缘 ──HTTP:80──► 腾讯云 nginx ──► 127.0.0.1:3425 / :3430
```

- 源站不配 TLS，CF 自动签证书、自动续期
- 不用 CF Tunnel（本机有公网 IP，反代更直接；Tunnel 需要 cloudflared 常驻）

## nginx 站点

文件：**`/etc/nginx/conf.d/magpie.sunfolower.cn.conf`**

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name magpie.sunfolower.cn;
    client_max_body_size 50M;

    location /v1/ {          # 网关（OpenAI/Anthropic 协议）
        proxy_pass http://127.0.0.1:3425;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection $connection_upgrade;
        proxy_buffering off;
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
    }

    location /v1beta/ {      # Gemini 协议
        proxy_pass http://127.0.0.1:3425;
        # 同 /v1/
    }

    location / {             # 管理网页
        proxy_pass http://127.0.0.1:3430;
        # 同 /v1/，proxy_read_timeout 300s
    }
}
```

> `$connection_upgrade` 来自 `/etc/nginx/conf.d/upgrade-map.conf`（已存在）。

## 为什么放 conf.d 而不是 sites-enabled

`nginx.conf` 的包含顺序是：`conf.d/*.conf`（第 59 行）→ `sites-enabled/*`（第 60 行）。
`nginx.conf` 语法只检查、不按站点优先级排序；但 **server 匹配按配置文件加载顺序**。

`sites-enabled/sunfolower.conf` 是 `listen 80 default_server` + `server_name _;`，
并且它按文件名顺序（`s` 在 `m` 之后）加载。放在 `conf.d/`（先于所有 sites-enabled 加载）能保证：
① `magpie.sunfolower.cn` 的 server 先被匹配；
② 不依赖共享目录里加前缀文件名。

> ⚠️ 首版曾误放 `sites-enabled/`，并靠重命名为 `00-magpie.sunfolower.cn` 抢加载顺序，
> 虽可用但会污染共享目录、与其他工具的命名发生冲突，已迁移到 conf.d。

## 鉴权要点

- 网页：URL `?k=<MAGPIE_WEB_KEY>` 登录，之后 400 天内凭 cookie。
- 网关：外部请求必须带 **enabled gateway key**（`Authorization: Bearer` 或 `x-api-key`）。
  经 nginx 转发的请求带 `X-Forwarded-For`，magpie 视为"来自其他机器"，无 key 直接 401 —— 这正是预期行为。
- **不要**设 `MAGPIE_TRUST_PROXY=1`，除非 nginx 自己做鉴权（这里没有）；开了会让代理后所有人都免 key。

## 相关：其他域名混用注意
